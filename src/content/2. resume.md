# 이력서

**Unity/C# 클라이언트 개발자** | 경력 2년 2개월

구조를 먼저 세우고 팀이 그 위에서 개발하게 만드는 일을 해왔습니다. WPF/XAML에서 익힌 데이터 바인딩 사고를 바인딩이 없는 Unity에 MVVM과 R3로 이식해 클라이언트 아키텍처를 세웠고, 그 구조를 팀에 교육하고 코드리뷰로 유지했습니다. 필요한 기술은 직접 익혀 붙였고, 그렇게 백엔드 서버와 인프라까지 영역을 넓혔습니다.

- **디지털 트윈 팩토리 메인 개발 리드**: 클라이언트 아키텍처 설계와 REST API 서버 단독 구축 (1년 1개월)
- **대형 3D 모델 로딩 5분 → 30초**: FBX→glTF 변환 파이프라인 구축과 IL2CPP 전환
- **VR 도장 시뮬레이션 물리 수식 설계**: 90fps 프레임 예산 안에서 매 프레임 3D 보간 연산
