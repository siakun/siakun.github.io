# 이력서

**Unity/C# 클라이언트 개발자** | 경력 2년 2개월

구조를 먼저 세우고 팀이 그 위에서 개발하게 만드는 일을 해왔습니다. WPF에서 MVVM을 다뤄본 경험을 바탕으로, 바인딩이 없는 Unity에서는 바인딩 시스템을 새로 만드는 대신 View가 Model을 구독하는 구조를 택했고, 팀이 유지보수할 수 있는 선을 함께 확인한 뒤 교육과 코드리뷰로 정착시켰습니다. 필요한 기술은 직접 익혔고, 백엔드 서버와 인프라도 그렇게 맡았습니다.

- **디지털 트윈 팩토리 메인 개발 리드**: 클라이언트 아키텍처 설계와 REST API 서버 단독 구축 (1년 1개월)
- **HoloLens 2 4인 실시간 멀티플레이 게임**: Rigidbody 물리 상태 동기화와 선형 보간 보정, 로비/룸 세션 흐름 설계
- **50~90MB 3D 모델 로딩 5분대 → 30초대**: 런타임 로딩 파이프라인 설계와 glTF 전환, IL2CPP 적용
- **VR 도장 시뮬레이션 물리 수식 설계**: 90fps 프레임 예산 안에서 매 프레임 3D 보간 연산
