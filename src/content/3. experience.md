### 1. 디지털 트윈 팩토리 (제조업체 대상)

**기간:** 2024.08 ~ 2025.09 (약 1년 1개월)
**역할:** 메인 개발 리드
**기술:** `Unity` `C#` `MVVM` `R3(Reactive)` `ASP.NET Core` `EF Core` `PostgreSQL` `JWT` `Git`

제조공장 설비를 3D 환경에서 등록/배치/관리하고, 공정 시뮬레이션으로 병목구간과 생산 효율을 실시간 시각화하여 최적의 설비 배치를 도출하는 디지털 트윈 솔루션

**백엔드**
- 요구사항 분석 → 아키텍처 설계 → 구현 → 릴리즈까지 전 과정 주도
- ASP.NET Core + EF Core + PostgreSQL 기반 REST API 서버를 설계부터 운영까지 단독 구축
- ERD 설계, CRUD API 구현, JWT 인증 처리
- 회원가입/로그인 및 RBAC(역할 기반 접근 제어) 기능 구현
- 서버-클라이언트 간 FBX 모델 파일 업로드/다운로드 시스템 설계

**클라이언트**
- 같은 데이터를 여러 화면에서 다르게 표현해야 해 갱신 로직의 동기화 누락이 잦던 문제를 MVVM 도입으로 해결, 컨트롤 단위 상태 분리로 UI 상태 버그 제로 달성
- uGUI용 바인딩 시스템을 새로 만드는 대신 View와 Model을 논리적으로 분리하고 View가 Model을 구독하는 구조 설계, UniRx와 R3로 리액티브 프로그래밍 적용
- 구조를 혼자 정하지 않고 작은 예제로 팀과 검토해 팀이 유지보수할 수 있는 범위에서 적용
- 팀 내 MVVM 교육 주도 및 UI 아키텍처 의사결정과 코드리뷰 담당
- 3D 모델 배치/이동/회전/삭제 및 레이아웃 저장/불러오기 기능 구현
- 빌드된 Unity 클라이언트가 사용자 업로드 모델을 런타임에 로드하지 못하는 제약을 Addressables로 풀 수 있는지 먼저 검토, 업로드 모델을 서버에서 AssetBundle로 빌드하고 배포하는 인프라가 필요해 라이브 서버 운영 부담, 업로드 반영 지연, 상용 라이선스 비용을 근거로 기각
- 대신 서버 파일 다운로드, 로컬 캐싱, 오브젝트 풀링, 인스턴스화를 하나로 묶은 런타임 모델 로딩 파이프라인 설계 (외부 로더 통합: FBX는 TriLib, glTF는 glTFast)
- 사용자 3D 모델 런타임 임포트 요구사항 대응을 위해 FBX → glTF 서버 변환 파이프라인 구축 (Blender CLI 기반, FBX2glTF 대비 변환 안정성 확보)
- 50~90MB 대형 모델 기준 로드 시간을 5분대에서 30초대로 단축 (glTF 전환 + IL2CPP, 테스트 빌드 계측)
- glTF LOD 미지원 문제를 MSFT_lod 확장으로 해결, 커스텀 LOD 처리 구현
- 카메라 시스템 (이동/줌/뷰 전환) 구현
- 큐와 코루틴 기반 공정 시뮬레이션 구현, 설비 간 물류 흐름과 병목구간을 실시간 시각화

**아키텍처 및 코드 품질**

- 커스텀 로깅 시스템 설계 (LogLevel 기반 제어, StackTrace 관리)

### 3. 페인트 도장 VR 시뮬레이션 VRush (대기업 중공업사 대상)

**기간:** 2023.12 ~ 2025.05 (약 1년 6개월, 병행)
**역할:** Unity 개발
**기술:** `Unity` `C#` `Python(NumPy/SciPy)` `Particle System` `Shader` `Compute Shader`

실제 도료의 물성 데이터와 물리 수식을 기반으로 분사 패턴, 도막 두께, 흘러내림을 정밀 재현하는 VR 도장 교육 시뮬레이션. 독성 도료와 위험한 작업 환경 탓에 현장에서 반복 연습하기 어려운 선박 도장을 VR로 훈련하고, 현장 투입 전에 피드백을 받도록 하는 것이 목적

**수식 기반 시뮬레이션**
- 이산 거리 데이터(300/400/500mm)를 연속 거리에서 사용하기 위해 X축 6차 다항식 × Z축 2차 다항식 기반 3D 보간 함수 y=f(x,z) 설계
- 6차 다항식 분사각 초과 시 발산 문제를 Piecewise 함수(구간별 분할 + 지수함수 경계)로 해결
- ML 추론 대비 정적 수식이 VR 90fps 프레임 예산에 적합하다고 판단, 매 프레임 수식 연산 방식 채택

**Python 데이터 분석**
- 엑셀 차트 수식의 6차 다항식 계수 정밀도 한계 발견 (소수점 2자리 → 8자리 필요), raw data에서 NumPy와 SciPy로 재산출하여 해결
- Python→C# 수식 자동 포팅 스크립트 개발, 다수의 도료 조건별 방정식을 일괄 변환

**Unity 시각화**
- VFX Graph / Particle System 기반 스프레이 분사 시각화
- 도막 두께를 색으로 나타내는 히트맵과 작업 경로 분석 구현, 과하게 칠한 구간과 덜 칠한 구간, 불안정한 작업 패턴을 교육생이 직접 확인하도록 지원
- 동적 메쉬 생성 (도장 쌓임/밀림 효과)
- Shader 기반 질감 표현 (부드러운 가장자리, UV 동적 생성)
- 흘러내림 효과 구현을 위한 Fluid Dynamic 조사 및 Compute Shader + 데칼 방식 기술 검토
